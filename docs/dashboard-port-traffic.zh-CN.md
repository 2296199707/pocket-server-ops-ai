# HY2 + SSH 流量统计

2026-09-13，接续未提交的轻量仪表盘改动。

## 口径与范围

- HY2 官方 /traffic 是代理业务字节，SSH 的 TCP 字节与它口径不同，不能直接相加。
- 新增独立端口统计：SSH 的 TCP 监听端口、HY2 的 UDP 监听端口，均以服务器接收/发送
  的 IP 字节为准；合计分别相加接收、发送，双向总量再相加。
- SSH 统计包含终端、SFTP/SCP、SSH 隧道和重传；不是单独的文件有效载荷。
- 端口被其他程序复用时，也计入该端口统计。不是供应商账单或整机全部流量。
- 使用内核 nftables 命名计数器，不新增常驻进程；手动开启/配置，仅操作
  inet pocket_server_ops_traffic 自有表，不修改既有防火墙表或服务配置。
- 开启时起算，重启、规则被移除或修改端口时重置。相同端口重复开启不重置。
  APP 按服务器缓存最近快照；缓存不能替代服务器持久计数，不提供月度账单历史。
- 刷新状态通过同一次 SSH 请求读取两次计数和系统启动时钟，计算短时速率。
  不引入后台高频轮询；缺失或无权限显示不可用，不当作 0。

## 实现与使用

- 仪表盘新增 HY2 + SSH 流量卡，合计置顶，下面是 SSH/TCP 与 HY2/UDP，
  各显示接收、发送、双向累计和刷新采样速率。
- 点击“配置端口”，确认服务器本机监听端口后安装计数规则。支持逗号分隔多个端口。
  SSH 建议值来自 SSH_CONNECTION 中服务器端口，不把 NAT 外部连接端口当作本机端口。
  HY2 建议值来自 ss 的本地 UDP 地址字段；检测不到可手动填写。
- 普通刷新只读规则，不安装软件、改变端口、清零计数或增加常驻服务。
  需要服务器已安装 nftables 且 SSH 用户有操作权限；不支持时显示原因。
- 保留独立 HY2 业务 API 指标，不与端口字节重复叠加。整机网卡指标也不加入两者合计。
- Linux 本机 input/output 端口统计，不覆盖 Docker bridge 转发链里的容器服务；
  容器使用 host 网络的监听端口可使用此统计。端口跳跃需填写实际本机端口。
- UI 复用原仪表盘的每服务器快照缓存；未获取、权限错误、损坏或缺失计数器不补零。
  采样期间规则重建/重置或时间无效时，保留当次可用累计值，不计算虚假速率。
