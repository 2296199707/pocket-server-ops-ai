# PocketServerOps AI v1.0.5-beta.11

- OpenCode 官方供应商请求增加稳定会话标识；其他供应商使用 PocketServerOps 自有标识。
- 独立只读工具支持同轮并发，混合写入操作的批次保持顺序执行。
- 优化任务事件事务写入、序号分配及界面通知合并。
- 增加 AI 请求与工具执行耗时记录。

发布复核：修正读取提前越过写操作的问题；提前启动的只读 Future 即使提前失败也有错误监听，结果仍由正常工具流程返回。
定向 Agent Loop 测试 31 项通过。尚未测量真实供应商下的端到端提速比例，不承诺固定倍数。
