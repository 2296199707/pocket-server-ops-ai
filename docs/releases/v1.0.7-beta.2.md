# PocketServerOps AI v1.0.7-beta.2

- 修复 nftables 1.0.6 未在 JSON 中返回表注释时，仪表盘误报“端口计数器数据无效”的问题。
- 从文本输出读取配置标记，核对表身份，继续使用 JSON 读取字节计数；保留规则重建时的速率校验。
- SSH 端口建议汇总实际监听端口，HY2 从运行服务配置读取入口，避免混入临时 UDP 端口。
- 端口仍可手动修改，多个端口用英文逗号分隔；自动建议不会覆盖已经配置的端口。

安装后打开仪表盘并刷新即可，无需重装服务器规则，也不会因本次更新清零已有累计。主动修改统计端口仍会重新起算。HY2 业务 API 未开启的提示与端口计数是两项独立功能。

验证：真实 nftables 1.0.6 输出、9 项定向测试及静态检查通过。

Android 版本：1.0.7-beta.2（versionCode 61）。
