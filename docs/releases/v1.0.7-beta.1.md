# PocketServerOps AI v1.0.7-beta.1

- 服务器仪表盘新增 HY2 状态区域，可读取进程内存、监听地址，以及已配置的本机统计 API 返回的在线客户端和业务流量。
- 新增 SSH/TCP、HY2/UDP 端口流量卡，显示接收、发送、双向累计、采样速率和两者合计，支持每台服务器的快照缓存。
- 支持配置多个监听端口、开启和停用统计。使用 nftables 内核计数器，不新增常驻进程。
- 修正 HY2 UDP 本地监听地址读取，修复端口配置弹窗关闭时的控件生命周期错误。

使用方式：更新仪表盘的状态脚本；在流量卡点击“配置端口”，确认服务器本机 SSH/TCP 和 HY2/UDP 监听端口后开启统计。服务器需已安装 nftables，连接用户需有操作权限。

端口累计从开启时起算，服务器重启或修改端口后重新计数；不是月度账单。HY2 业务 API、端口统计和整机网卡统计分别显示，避免重复相加。Docker bridge 转发流量不在本机监听端口统计范围内。

验证：7 项定向测试和静态检查通过，包含隔离网络命名空间中的真实 TCP/UDP 计数与手机宽度弹窗交互。

Android 版本：1.0.7-beta.1（versionCode 60）。

APK 约 80.7MB，签名与正式版 1.0.6 一致，可覆盖安装。APP 内开启测试版更新后检查更新即可获取。
