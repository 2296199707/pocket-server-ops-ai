# PocketServerOps AI v1.0.7-beta.3

- Agent 可主动查看手机项目、已授权目录和当前对话附件中的图片，生图结果也会返回给模型检查。
- 新增服务器图片查看工具，支持多服务器选择，无需绑定手机项目。AI 可先通过服务器命令生成网页截图，再读取图片检查。
- 新增本地网页截图工具，返回独立 WebView 渲染的视口图片。
- 图片工具结果使用独立附件存储，历史记录只保留引用，重启后可恢复。
- 新增“设置 → 仪表盘设置 → 流量监控”，默认关闭。关闭时隐藏 HY2、SSH 及合计流量并停止相关采集，CPU、内存、磁盘和整机网络照常显示。
- 开启流量监控后，在指定服务器仪表盘中通过“配置端口”安装统计。关闭开关不会删除服务器已有规则或清零累计值；旧状态脚本也无需重装即可停止 App 的 HY2 采集。

看图需要对话模型支持图像输入。本地网页截图不是用户浏览器当前交互状态；WebGL、视频等硬件合成内容可能无法完整捕获。本批次未做真机截图及真实供应商视觉实测。

验证：图像链路、服务器图片路由、历史恢复及可选流量监控的定向测试、静态检查通过。
