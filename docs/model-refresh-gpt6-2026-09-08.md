# GPT-6 模型刷新排查与修复

2026-09-08，用用户授权的临时 API 实测 https://ai-pixel.online/v1：

- GET /models：HTTP 200，9 个模型，含 gpt-6-astra。
- GET /models?client_version=0.150.0：HTTP 200，6 个模型，不含 gpt-6-astra。

根因是 APP 默认附带固定 Codex 版本参数，触发供应商的另一份目录；不是本地模型白名单，也不是未知模型解析失败。不能仅检查 HTTP 成功来判断目录是否完整。

修复：默认请求标准 /models，标准请求被 400/404/405/406/415 拒绝时才尝试带版本参数请求。保留模型元数据解析和 OpenCode 目录能力补充，不自动改变用户默认模型。

另修复刷新推理参数后抽屉模型列表不同步；供应商编辑页显示获取模型数量。回归模拟同样的版本参数过滤行为，验证 gpt-6-astra 可见且正常刷新只请求一次。
